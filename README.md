## About Eligibility Checking Engine

Eligibility Checking Engine is a prototype built to support education-related eligibility checks for schools and local authorities. It focuses on guided flows that help users work through family and child eligibility decisions, with emphasis on free school meals and childcare scenarios.

The project is presented as a web experience and is useful for exploring policy-driven forms, decision paths, and application handoffs in a GOV.UK and DfE context. It is intended as a prototype environment rather than a finished production service, making it suitable for demos, internal review, and iterative development.

## Features

- Check eligibility for families and children through structured prototype flows
- Support free school meals application paths
- Include an appeal path for eligibility decisions
- Finalize FSM application steps
- Separate prototype journeys for FSM and childcare
- Web-based interface for browser access
- Designed around school and local authority eligibility scenarios
- Aligned with GOV.UK and DfE-style service concepts

## Usage

Open the prototype in a browser and follow the eligibility journey that matches the scenario you want to test.

Typical workflow:
1. Start with the family or child eligibility check.
2. Continue into the free school meals or childcare path as needed.
3. Review the eligibility outcome.
4. Use the appeal or finalization steps where the flow provides them.

Because this is a prototype, the exact path may vary by scenario and build version. Use it to test service logic, compare journeys, or validate content and interaction design.
